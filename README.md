# Ledger Pilot 账本管家

本地优先的个人记账应用。支持导入并合并微信/支付宝账单、手动补录例外流水、用精确规则预填后搜索或批量人工确认，并在 Web 总看板按年度、月度或自定义范围查看有效标签下的财务结果。完整版本描述见 [RELEASE_NOTES.md](RELEASE_NOTES.md)。

## v1.6.0 新增

- 流水标注增加高级筛选器，覆盖归一化流水表的 16 个字段；同字段的多个“包含”条件取并集，不同字段取交集，“排除”条件会在最后剔除命中项。
- 每个字段可按类型使用精确匹配、模糊包含、闭区间或为空判断；交易时间和金额支持首尾范围，日期上限包含当天全天。
- 全局模糊搜索可在全部 16 个字段中选择包含或排除，并能与月份、有效分类、有效渠道、标注状态和任意高级条件正交组合。
- 已应用条件会显示为可单独移除的筛选标签；日期高级条件会主动接管并替换月份快捷轨道，避免隐式截断跨月结果，可一键恢复月份范围。
- 修改任一筛选会立即废弃旧请求并清空批量选择，慢响应不能覆盖新条件，也不能把已被排除的流水误送去批量标注。
- 新增结构化 `POST /api/transactions/search`，保留原有 `GET /api/transactions` 兼容入口。

- 自定义范围既可直接输入日期，也可在全年日历中点击选择开始与结束；按日、周、月选择时会自动吸附对应周期。
- 收支曲线新增日、周、月三种颗粒度，并与看板时间范围保持正交，切换曲线颗粒度不会改变统计边界。

## v1.0.0 能力

- 导入微信支付 `.xlsx`、支付宝 `.csv` 或包含这些账单的加密 `.zip`，永久保存每次导入原件和不可变归一化记录；解压密码仅在内存中使用。
- 同时导入多份使用不同密码的压缩包时，可按行输入密码，或直接粘贴“平台：密码”格式的密码文本。
- 以 `(来源平台, 交易单号)` 幂等更新唯一总账；重复导入仍保留批次记录并写审计日志。
- 管理任意层级标签树：维度、父子标签、备注、排序、启停和使用次数。
- 安全删除标签：无引用时删除，有流水引用或子标签时自动停用。
- 配置“交易对方完整名称”的精确匹配规则，只负责给人工标注弹窗预填默认值。
- 在流水弹窗中查看原始事实、修改标签、保存、上一条、跳过或保存并下一条。
- 人工结果始终优先于规则建议；看板和流水明确展示“人工 / 规则 / 未确认”来源。
- 查看月度收支、趋势、支出分类、支付渠道和可筛选流水。
- 查询重复导入、导入失败、规则、标签和人工标注审计日志。

v1 不接入任何 AI 服务，不需要模型 URL、API Key 或外部网络。也不提供预算、删除原始流水或桌面壳。

## 数据流

```text
微信 xlsx / 支付宝 csv / 加密 zip
          │
          ▼
  导入批次 + 原件留存
          │
          ▼
   不可变归一化记录
          │
          ├── 重复：保留记录 + 审计
          ▼
      SQLite 唯一总账
          │
          ├── 精确规则建议
          ├── 人工确认（优先）
          ▼
      月度看板与流水
```

运行数据默认保存在 `backend/data/`，已被 Git 忽略；原始账单和数据库不会进入版本库。

## 本地启动

需要 Python 3.11+ 与 Node.js 20+。

### 1. 后端

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

健康检查：`http://127.0.0.1:8000/api/health`；OpenAPI：`http://127.0.0.1:8000/docs`。

### 2. 前端

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。Vite 会把 `/api` 代理到本机 `8000` 端口。

## 使用顺序

1. 在“标签管理”中确认或扩展收入分类、支出分类、支付渠道、业务类型和特殊标签。
2. 在“预填规则”中为高频交易对方创建精确规则。
3. 导入微信或支付宝账单；现金、银行卡直入等例外流水可使用“手动记账”。
4. 进入独立的“流水标注”页，用全局模糊搜索、有效标签快捷筛选或高级条件筛出相似流水，再逐笔确认或多选统一标注；保存后流水会自动离开待办队列。
5. 返回总看板，按年度、月度或自定义范围查看人工确认后的统计。

被引用的标签删除后会转为停用，历史引用不会丢失。规则只匹配交易对方完整名称，不匹配关键词或商品说明。

## 运行参数

- `LEDGER_PILOT_DATA_DIR`：导入原件目录。
- `LEDGER_PILOT_DATABASE_URL`：覆盖默认 SQLite URL。
- `LEDGER_PILOT_CORS_ORIGINS`：允许访问 API 的 Web 来源，逗号分隔。
